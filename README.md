# Agent Skills

Personal agent skills for coding assistants.

## Install

```bash
npx skills add PhilippOesch/agent-skills
```

Install a specific skill:

```bash
npx skills add PhilippOesch/agent-skills --skill tdd
```

## Available skills

| Skill | Description |
|-------|-------------|
| caveman | Ultra-compressed communication mode |
| code-review | Two-axis review of changes since a fixed point |
| grill-me | Relentless interview to sharpen a plan or design |
| grill-with-docs | Relentless interview that also creates docs |
| grilling | Grill the user relentlessly about a plan |
| grilling-in-cave | Grilling session in caveman mode |
| handoff | Compact conversation into a handoff document |
| i-have-adhd | Shape output for readers with ADHD |
| implement | Implement work based on a spec or tickets |
| implement-spec | Implement the result of /to-spec and /to-tickets |
| improve-codebase-architecture | Surface architectural friction as an HTML report |
| mermaid | Generate self-contained HTML mermaid diagrams |
| research | Investigate a question against primary sources |
| rmslop | Remove AI-generated code slop |
| tdd | Test-driven development |
| to-spec | Turn conversation into a spec in the issue tracker |
| wait-what | Re-pitch the last message in simpler terms |
| wayfinder | Plan a large chunk of work as decision tickets |
| writing-for-agents | Write documents that agents consume well |
